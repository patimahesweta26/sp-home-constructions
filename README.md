# SP Home Constructions

Business website for SP Home Constructions — construction & repair services in Bhubaneswar, Odisha.

Live: https://sp-home-constructions.vercel.app/

## Pages

- `/` — Home (construction company in Bhubaneswar)
- `/about.html` — About Us
- `/services.html` — Services overview
- `/services/home-construction.html` — New Home Construction
- `/services/renovation.html` — Renovation & Remodeling
- `/services/repair-maintenance.html` — Repair & Maintenance
- `/services/waterproofing.html` — Waterproofing
- `/services/design-planning.html` — Design & Planning
- `/services/project-consultation.html` — Project Consultation
- `/projects.html` — Project gallery
- `/contact.html` — Contact form + map

## SEO

- Unique title/description/canonical/Open Graph per page
- JSON-LD structured data (HomeAndConstructionBusiness, Service, FAQPage, ImageGallery, ContactPage)
- `sitemap.xml` + `robots.txt`
- `404.html` custom error page

## Contact form

Submissions POST to Formspree (`https://formspree.io/f/xgogbzrj`) and open WhatsApp with the enquiry. Formspree submissions are visible in the Formspree dashboard and exportable to CSV/Excel.
